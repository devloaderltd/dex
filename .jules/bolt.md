## 2026-05-06 - Optimize PurDexStakingRewards.sol updateReward modifier\n**Learning:** The updateReward modifier in StakingRewards contracts often calculates and caches 'rewardPerTokenStored', but then calls 'earned()' which redundantly recalculates 'rewardPerToken()'.\n**Action:** When working with StakingRewards logic, always check if the update modifier can pass the cached 'rewardPerTokenStored' value directly to the user balance calculation instead of making redundant function calls and SLOADs.
